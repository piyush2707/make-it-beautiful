# Prompt examples

Use these with your coding agent after installing Make It Beautiful. Adapt the wording to your project.

## General polish pass

> Use Make It Beautiful to polish this page. Keep the current functionality and content. Inspect the implementation first, then improve hierarchy, spacing, typography, and responsive behavior. Make a focused set of changes and tell me what changed.

## A more considered landing page

> Help this landing page feel less like a starter template. Keep the brand and message intact. Improve type scale, content width, section rhythm, CTA hierarchy, and visual consistency. Avoid unnecessary dependencies and decorative effects.

## A busy dashboard

> Review this dashboard for scanability. Make key metrics and the next action easier to find, reduce visual noise, and keep dense information readable. Preserve all existing data and interactions.

## Mobile-first review

> Review this screen at narrow widths. Look for overflow, cramped controls, awkward wrapping, and sections that lose hierarchy on mobile. Fix those issues without degrading the desktop layout.

## Forms and feedback

> Improve this form's usability. Check label clarity, field spacing, focus states, validation, loading, success, and error feedback. Keep the existing submission logic.

## Existing design system

> Use the design tokens and components already in this repository. Find inconsistencies and bring them into line with the current system rather than inventing a new visual language.

## Critique before code

> Don't edit yet. Inspect this page and give me the five highest-impact design improvements, ranked by user impact and implementation effort. Ground each point in the actual code and content.

## Reference image

> Use the attached reference as direction for mood and hierarchy, not something to copy blindly. Adapt the useful patterns to this product, its content, and its constraints.
